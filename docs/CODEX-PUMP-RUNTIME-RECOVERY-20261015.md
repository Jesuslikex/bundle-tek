## Implemented

- Read-only nonempty original-blockhash v1 replay qualification, with coherent pre/post banks, continuity, bounded reads and cancellation. The sanitized live probe used a public validator identity, zero user wallets and unsigned zero-value self-transfers. It reported two sequential fees of 5000 lamports. No signatures or sends occurred.
- Full bounded executable code collection with before/after loader, deployment and authority checks. The separate live identity probe measured seven listed protocol programs across slots 457075389 through 457075419, using 25 reads and 13,807,715 ELF bytes. This is historical provider evidence, not an owned launch-group approval or independent semantic audit. Native System identity is account data, not executable ELF code. Receipts are the two sibling JSON files.
- Owned per-group runtime previews bind every packet program and creation CPI program to the original manifest, document, simulation and public metadata. Runtime review expires within 30 seconds. A separate explicit user acknowledgement accepts the exact hashes and upgrade authorities and acknowledges that no semantic audit has been established. Measuring current code alone never approves it.
- Authorization repeats full owned funding/economics/source validation, then rechecks current loader/deployment/authority headers. Immutable SQL guards repeat ownership, wallet revisions, folders, metadata, consent, state and expiry at insertion. The returned authorization lasts at most five seconds and permits complete-group signing only. Submission and execution remain false. Upgradeable programs can still change after observation; consent explicitly acknowledges that trust boundary.
- Browser signing requires the saved draft, every limit, encrypted mint backup acknowledgement, both passphrases and three initially unchecked approvals. Mint and wallet keys stay in browser vault sessions and temporary sessions are cleared. Guards run around every asynchronous signing step. The entire independently verified signed vector is retained before registration; retries save existing bytes instead of signing again. A corrupt browser backup can fall back to independently verified server-retained bytes for export. No group broadcast transport or automatic signing was added.
- Recovery collects fresh finalized evidence itself. Append-only event-backed transitions release reservations only for expired unobserved groups with linked finalized mint absence, or all-finalized failures with known fees. Signatures and history remain immutable. Pending, partial, unknown and successful-but-economically-unreconciled groups remain reserved. Closure does not establish economic settlement or audited P&L.
