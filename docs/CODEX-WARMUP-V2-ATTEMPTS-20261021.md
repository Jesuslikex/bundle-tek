# Fresh unsigned warmup attempts

Local source checkpoint, 21 October 2026. This connects an explicitly approved quote and simulation preview for the first pending v2 warmup action. It does not start a long-running warmup session, authorize signing or execute a trade. No application or hosted database was migrated, and nothing was deployed.

## Resulting flow

The existing plan approval and saved history remain separate steps. After explicitly beginning the pending action review, the user can separately request its unsigned preview. The server derives the wallet, side, amount, saved-buy source, budget and original finish from the owned immutable session. Client requests cannot replace those selectors.

Migration 0134 adds immutable attempt leases and outcome storage, a source-context view, four unique indexes and twelve new restrictive triggers. The outcome stores the summary, private unsigned packet and canonical fee evidence in one guarded INSERT. Every prior migration, journal entry and old schema/trigger body stays unchanged. 0134 must not be changed after this checkpoint is committed.

SQL time enforces the original policy: at most one unknown or unexpired attempt, at least 30 seconds between requests, up to three attempts per action, the captured overall bound, and an attempt expiry no later than 60 seconds or the original finish. A refusal or cancelled/unknown provider outcome still consumes its immutable attempt. Only the handler confirmed to have created the lease calls providers. Repeating an ID recovers its saved lease; it never repeats an existing provider run. The core accepts a typed lease and performs its own fixed SQL check; its legacy default retains the original cooldown path.

The real quote/envelope parser and existing simulation path are reused. Fee evidence preserves the exact integer formula `max(signature + priority, observed network fee) + rent`, capped by the original reserve. An explicit remaining-unit record is required for a captured saved-buy Sell. The private record hash binds the complete lease, summary, packet bytes and fee document. Public DTOs contain no transaction bytes or private source. They carry an explicitly historical, prefix-replayed original head rather than pretending it is current status.

Pause and Stop remain independent of a running provider request. Source/head changes, expiry and cancellation prevent late publication. The child preserves the original request before POST, offers explicit saved-only recovery, and never fetches or retries automatically on mount. A 404 does not prove an earlier handler failed; a separately unchecked retry uses the same original ID. A later request first retains a verified local archive. Discovery is an explicit GET, returns at most 25 owned IDs per page, and does no provider work. An older recovered entry stays historical; only the newest discovered ID can become a missing current reminder. Local archives render ten entries at a time. Stop remains usable while the child is busy.
