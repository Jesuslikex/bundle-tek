## Stored recovery boundary

The internal journal store retains one immutable root per server-owner/saved-consent identity. A future caller must supply its owner from a verified session; this library does not authenticate an HTTP request and has no HTTP caller. It independently replays the original consent and retained review source, rebuilds the original public review with the existing plan/progress/performance builders, verifies its original context digest and manifest, and binds the derived exact source bytes, source hash and domain-separated initial head. Historical construction uses the original consent creation time, never today's time as a renewed review start. Recording a root is recovery metadata, not starting a session or reserving money.

Roots and events are immutable against UPDATE, DELETE and INSERT OR REPLACE. Owner and consent foreign keys, unique owner/consent and owner/event identities, parent lifetime/identity bindings, false authority flags and byte/count limits are guarded in source-only0124; full original source/hash/manifest replay also runs in the service. Each append must atomically follow the latest stored version and hash, with a nondecreasing canonical timestamp and total source/event capacity at most4MiB and4096events. A prevalidated stale writer cannot replace a competing committed transition. This serializes journal history without reserving wallets or funds.

The reader obtains the root, separately retained head and complete ordered event vector in one SQL statement/snapshot. The head is initialized with the root and advances in the event INSERT's transaction. Its guards permit only the corresponding just-inserted next event, not a direct reset, advance, replacement or deletion. If head advancement fails, the event INSERT rolls back. A missing tail cannot hide behind a head derived only from the remaining rows: stored count, hash, bytes and final timestamp must all match. This corrected a gap found during Codex self-review before publication.

The reader verifies every event's raw digest and metadata, replays the full chain through the unchanged sequencer and returns only false capability flags. The durable event UUID is inside its hashed document and must match the separate SQL identity; it cannot be relabeled without invalidating recovery. The shared replay decoder accepts this optional canonical UUID for compatibility with earlier non-stored internal journals, while0124 and this writer require it. Missing immutable guards, source mismatches, changed event bytes/columns or inconsistent transitions withhold the recovered state. The returned internal object includes source/plan/history for the next consistency check and must not be serialized directly as an HTTP DTO. No API or browser caller exists yet.

The writer currently accepts only review-slot, observed submission/unknown outcome and explicit Pause/Resume/Stop bookkeeping. Inputs cannot override server time/version/predecessor/UUID or add capabilities. In-flight observations remain held after expiry. Begin-review expiry is checked again after asynchronous hashing/replay and by the database's clock at insertion. **Finalized settlement is refused by both the service input schema and SQL**, because receipt labels alone do not prove a transaction. Actual finalized receipts and budget settlement must be integrated through the real receipt replay adapter with insertion-time source guards in the next stage.

Every write has one INSERT attempt. A rejected response is treated as unknown, then read by its original identity with a separate bounded recovery signal. An exact same-ID call for an already saved record returns that record without another INSERT; changed identity/contents/predecessor refuse. Cancellation after commit leaves the saved record available for explicit same-ID read recovery. An absent read does not prove the write never committed and does not authorize a replacement or automatic retry; an unknown outcome must be recovered through the read path rather than another append invocation. A second root ID for one consent is refused, not silently substituted.
