23 October 2026. Base d72e272. Local transport primitive only; no storage table, writer, API, human consent, signing or execution.

## Format and trust boundary

The separate proposal-content-v1 envelope contains the full strict execution terms and verifier evidence, including all raw asset observations and the complete fresh budget. It deliberately contains no approval or root and invents no publication time. The old flat-manifest archive and its 16 MiB limit remain unchanged. Original review and asset timestamps remain byte-bound and are never refreshed during recovery.

The new BLOB header pins owner, root/consent/review IDs, complete proposal SHA, terms SHA, verifier SHA, original asset expiry, total bytes and every ordered chunk descriptor. Strict format-tagged canonical structures distinguish proposal, terms, verifier and header content. Chunk and whole-proposal digests are raw SHA256; a single chunk has the same hash as the complete proposal. There are no cryptographic domain prefixes. An independently admitted owned header SHA and IDs are required when reading. Taking that expected selector from the incoming header defeats the trust boundary; no production caller exists yet.

Chunks are at most 192 KiB; a local 64 MiB ceiling bounds input bytes and rejects larger incoming headers before copying their payloads. Peak memory can be several times that input ceiling because detached chunks, assembled bytes, UTF16 text, parsed objects and canonical output coexist. This ceiling is an explicit transport resource policy, not a measured universal upper bound, storage quota, production capacity or hosted-limit qualification. The source-admissible maximum plan fixture is tested. The earlier 4800-action model stress specimens were not source-admissible and are not relabeled as such. Future durable admission still needs owner-wide staging/history byte quotas and bounded orphan handling before accepting uploads.

The reader captures header, expected selector and all exact-size chunks before its first await. It verifies the independently selected header SHA, contiguous descriptors, per-piece hashes and complete byte hash before a single fatal UTF8 decode. Missing, duplicate, reordered, short, extra, corrupt or noncanonical content refuses with a fixed error; no partial proposal escapes. Strict JSON shape and canonical roundtrip reject unknown fields, duplicate-key/whitespace encodings and the old archive domain. Cancellation is rethrown without replacement attempts.

Terms validation and exact asset/budget/verifier digests and owner/review/source/identity/expiry links are replayed. This is structural transport integrity, not actual asset decoding or economic admission. A self-consistent fabricated budget may be transported; the owned-parent reconstruction must still refuse it. Tests explicitly demonstrate that distinction with a rehashed invented historical amount. All human/current-source/signing/execution/automatic flags remain false. The existing verifier shape is exported without changing its schema or the current proposal/reconstruction algorithms.
