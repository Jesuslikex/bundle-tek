## Delivered behavior

The saved Front/Back snapshot review now offers **Load saved SOL observations**. The owned GET selection uses the exact source project and snapshot ID. The server verifies the saved record and current source/wallet/folder references, reads only those role addresses from the owner's retained native observations, then verifies the plan again before returning evidence. Foreign access, changed references and inconsistent retained data refuse publication. No RPC, quote, packet, deposit or financial action is called. It does not update stored observations or any planning settings.

Each funder, developer, Front, Back, temporary and final-holder row keeps its immutable role/order and exact buy, fee, rent and reserve ceilings. For native quotes, SOL buy principal joins that row's native ceiling. Stock-token buy ceilings stay separate from SOL, with live quote balances and scaled-mint units explicitly unverified. The funder ceiling is only its own declared fees/rent/reserve; exchange deposits and transfers to other roles are not calculated.

The comparison shows a retained public-address SOL amount, its original observation time, confirmed slot and provider hostname, and an integer difference from the declared native ceiling **at that observation**. Missing or invalid observations remain unavailable rather than becoming zero. A real saved zero stays zero. Amount spelling, u64 bound, formatted amount, address, stored slot, chain/currency/decimals, snapshot ID, timestamp and source shape are checked. Future timestamps and rounded/inconsistent records are unavailable. There is no freshness or spendability claim: new observations must be requested separately in My wallets.

A combined observed total is shown only when every role has evidence from the same snapshot ID, slot, observation time, provider and commitment. Mixed or missing observations never produce a pooled balance. Role filters change presentation only. No fund, sign, send or export action is introduced; all returned authority flags remain false. Existing stock/group qualification limits, signing consent and lifetime/custody checks are unchanged.
