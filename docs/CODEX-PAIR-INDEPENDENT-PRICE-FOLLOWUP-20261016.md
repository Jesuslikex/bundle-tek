# Independent stock price review follow-up

## Separate missing-price consent

A missing independent market comparison now requires its own initially unchecked checkbox with the exact text: “No independent price check is available for this order.” It is separate from exact-order consent and from the worse-than-2% acknowledgement. Requoting, context changes, expiry and a completed authorization attempt clear or invalidate it. The server accepts only an explicit boolean, bound inside the exact hashed authorization consent; missing, false, null, numeric and string acknowledgements fail when the comparison is unavailable.

New additive migration `0091_pair_order_independent_price_consent` adds a second BEFORE INSERT authorization trigger. Existing ownership, immutable reviews, one authorization per review and maximum five-second rules are not rewritten. The trigger treats missing/false/malformed availability as unavailable and requires a literal JSON `true` acknowledgement. No historical migration is edited or remotely applied.

Initial verification: four review/service/authorization/panel files pass 65 tests, including raw local-SQL insert refusal for missing/false/nonboolean acknowledgement, server consent refusal, separate UI checks and reset behavior. Full migration and combined verification follow after server quote pricing and selected-market handling. Stock signing remains hard-disabled. No push or deploy.

## Server quote USD observations and exact selected-pool binding

The review no longer looks for an imported quote-asset project. It reads the exact unscaled quote mint through the existing read-only, bounded DEX Screener adapter. This remains independent of the Jupiter preview/order; there is no USDC/USD peg constant. Quote-price IO starts alongside packet preparation and code IO, so it is not inserted after the final on-chain recheck. Read failure/timeout, a missing saved base observation or mismatching units produce the explicit unavailable-price consent path. Scaled base or quote assets skip this comparison and quote-price IO entirely until the provider's scaled units are confirmed.

The selected base-pool address is parsed separately from the strict quote/preflight request, validated against the latest saved owned market observation, bound into the immutable review hash and verified by the client. Missing/unknown selection never silently falls back to `pairs[0]`. A three-second maximum quote read and the normal <=5-minute source-read freshness apply. The exact server quote observation is retained in the review and reused while fresh at authorization, alongside a new owned base-observation check. Fetching a new timestamp cannot invalidate every approval. A changed saved comparison, revision, selection or expired reading requires a new review. Existing minimum-output and integer worse-only >2% math remain unchanged.
