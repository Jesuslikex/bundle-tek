# Auto Sell: reminders and saved approval discovery

Source base `4f56dc29e9a322bae47238e1299f6b9247afb84c`. Owned source checkpoint, no deployment or funded action. This improves outcome discoverability; it does not implement finality reconciliation or a durable executing session.

## User flow

Transaction reminders now have their own initially collapsed list, independent of the rolling activity log. The runner retains up to 100 detached, frozen, syntactically validated references, the first reference per retained intent. Overflow is explicit and points to saved history. Submitted reports and unknown outcomes are distinguished, with neither presented as a finalized sale. This list belongs to the current/last in-memory runner and still resets on context remount or a new run.

**Find saved Sell approvals** is available even without an in-memory log. Nothing is fetched when this disclosure mounts or opens. The user explicitly reads the latest page, an older page or an exact approval ID through the existing authenticated signing-history GET. The view covers this project's token-to-SOL Sell approvals **from any source**, not exclusively Auto Sell. It reports scanned records separately from matching rows, keeps pagination on a zero-match page and replaces pages instead of accumulating an unbounded list. An exact ID can also recover a record when a whole page cannot be admitted. Surrounding spaces are trimmed, and malformed IDs get a no-read explanation.

These are stored approval states. Even a stored finalized state says that receipt proof was not loaded. Original revisions, raw token units, saved timestamps and recorded signatures remain historical. A separate browser load time does not renew them. No counter is reconciled, no amount is freed, no run is resumed and no transaction is signed or resent. A registration that never reached the server may leave an awaiting-signature record; the missing local signature is not reconstructed.

The existing API response includes unsigned review documents. They still cross that authenticated transport. The new projection discards those documents and retains/displays no packet or receipt object. No browser storage key is added. Redelivery after reload is a new explicit owner-checked GET, not restoration from an unauthenticated local cache.

## Read and interaction boundaries

- Reuses `importedApprovalPage`, then checks the exact project/mint/ID/cursor scope, amount/signature/timestamp syntax and cursor progress. A mismatched token refuses the page; it is not silently skipped. The original import/refresh route derives identity from stored chain/address, and its UPDATE does not change those identity columns. Error text still explains that older pages can become unavailable.
- Reads at most 1 MiB of actual response bytes with fatal streaming UTF-8 decoding, cancellation and a 15-second read deadline. Declared oversize, malformed/empty/locked bodies and late replies are refused without raw parser/HTML diagnostics.
- Previous historical pages survive ordinary read/503/context errors. Explicit 401/403/404 access refusals clear them. Cancellation, source-key changes and unmount cannot publish a late result. There is no automatic read, retry, POST or RPC call in the new history view.
- Native output/status announcements and result-heading focus cover success and pagination. Cancel/error restores the read button; a user who moved outside the controls is not pulled back. Native disclosure markers and explicit input labels are preserved.
- The configure dialog can open while the workspace is locked so saved history is accessible. Run remains disabled, its handler still returns before vault/lock access, the old context key still invalidates previous work, and the preview-feed effect now refuses locked views. History access is not signing consent.
- Inner context replacement safely closes the old dialog/read and returns focus to the new connected trigger with an explanation. Full wrapper removal does not focus another owner's component or restore old settings. Whole-parent remount/navigation focus remains outside this owned slice.
