## Behavior

The panel displays 0.0..1.0, sending exact integer tenths in the optional waveIntensityTenths field. At zero the existing tight payload remains unchanged. At ten a streak fills available wallets, bounded by the existing six-wallet cap and remaining rounds. Intermediate values use a seeded extension probability. Legacy plans without the field keep the original planner draws and serialized output; six SHA256 fixtures were captured before editing from a087a14.

Estimates and saved sessions display the selected intensity. Changing the slider clears the previous estimate. Server validation rejects malformed tenths and a conflicting legacy wave flag. Existing round, amount, timing, custody, approval, signing, send and recovery rules are unchanged. Each wallet's sell follows its own finalized buy in a later reviewed batch. No migration is needed.
