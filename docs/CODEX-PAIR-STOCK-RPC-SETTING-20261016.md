# Separate stock runtime evidence endpoint

Clock policy is the separate commit 42e2729. This checkpoint adds server-only SOLANA_STOCK_RUNTIME_RPC_URL and getSolanaStockRuntimeRpcEndpoint. When unset or empty, selection falls back to the existing getSolanaIndexerRpcEndpoint chain, including its existing mainnet fallback. No new hard-coded public URL is introduced. A configured override must be HTTPS without user-info or a fragment; invalid overrides refuse rather than silently rotating to another endpoint. Error messages never include credential-bearing URLs.

Only the stock-pair order-first evidence lifecycle, original unsigned runtime preview and their future gated recheck select this endpoint. Their account/mint/Clock, lookup, code, simulation, fee, lifetime and genesis reads remain on that single selected runtime endpoint. Ordinary quote-only services, holder/indexer/history readers, native trading and group signing retain their prior selectors. The quote dependency factory accepts an internal server endpoint argument; no client request field accepts an endpoint or policy.

The unsigned qualification tool keeps reference discovery/history and its final quiet-reference audit on the existing indexer. It uses the selected stock endpoint for stock evidence, verifies that endpoint's mainnet genesis before mint observation, and records only its role and hostname. It never saves a credential-bearing URL. If no override is set, the tool explicitly labels existing-indexer-fallback; this cannot be claimed as verification of a separately provisioned validator.

The explicit unsigned-stock-qualification transport profile uses the same method-counted scheduler as the prior Helius-only profile: nine methods per rolling second, 112 ms per unit, maximum two methods per batch, independent ordinary pacing, cancellation and no retries. Its explicit server-only scope permits a standard HTTPS validator host. The old Helius-only opt-in still rejects other hosts, ordinary production callers keep configured pacing, and merely creating a qualification profile does not throttle unrelated reads. All 1 MiB raw packing, 720 KiB slices, response byte bounds, per-response floors, strict batch mapping and 32-slot checks remain unchanged. A fake-clock test checks the same nine-unit budget on a non-Helius host and ordinary-read isolation.
