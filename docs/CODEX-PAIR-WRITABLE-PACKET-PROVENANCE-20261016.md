# Writable-account packet provenance

The approved-clock sample captured an executable loader-owned address in the runtime's writable inventory, but did not retain its original compiled packet privilege map. The available receipt proves the guard operands, not whether Jupiter declared that address writable or an account/lookup mapping supplied the wrong role. Do not claim a decoder bug, permit that program by ID, or reconstruct missing historical bytes from a new order.

This checkpoint adds private, lazy packet provenance at the same before/after inventory and simulated-post-state refusal boundaries. It binds the existing verified packet SHA256, compiled account index, static versus loaded-writable/loaded-readonly section, declared signer/writable flags, static/loaded counts, instruction account positions and top-level program use. For loaded accounts it also records the original lookup table address, original table entry index, validated table snapshot hash and observation slot. Global lookup ordering is all tables' writable addresses followed by all tables' readonly addresses; tests cover both sections across two tables. Inventory row position/count refer to the actual <=100-account request chunk, while simulation position/count refer to the exact writable vector requested for simulation.

The helper supplies diagnostics only. Existing code still computes and uses its original writable list, resolves/rechecks tables through the same reader and applies the same rejection predicate. Provenance is evaluated only after the guard refuses. Malformed, missing, oversized or inconsistent evidence becomes explicitly unavailable; callback failure cannot replace the original refusal or grant acceptance. No instruction bytes, full unsigned packet, keys or credentials are persisted by this addition. Existing diagnostics remain non-enumerable and are absent from API serialization. The bounded unsigned CLI now explicitly copies the new safe numeric/string/boolean fields and fingerprints the helper source; it is not a public API debug response.
