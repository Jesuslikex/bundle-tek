# Authenticated Counter Buy pricing API

14 October 2026. POST /api/imported-projects/counter-quotes exposes the previously verified Counter ExactOut pricing adapter. The same-origin JSON request contains exactly projectId, projectRevision, planId, planRevision, decisionIdentity and maximumSolAmount. The last field is a positive plain-decimal SOL swap-input limit, converted independently to u64 lamports. Client targets, classifications, token mints and alternate payload fields are rejected.

A joined owner-scoped SQL query reads the Counter plan and current Solana project together. The complete plan/ledger decoder and stored row identity checks must pass. Before provider access, the API requires an active Buy plan, an exact recorded proposal, the requested plan/project revisions, unchanged saved project document, active project and matching mint/precision. The existing shared imported-token quote rate gate enforces 15 seconds per owner. Provider configuration is used only server-side.

After the quote, the joined context is read again. Any plan document/revision/state change or project document/revision/archive/identity change withholds the preview. Expired or cancelled responses are also withheld. Responses are no-store and retain executionAllowed=false. No proposal, approval, signature or transaction is created or consumed; only the existing request rate gate is updated.
