## Delivered flow

The existing Pump holder-launch screen dynamically opens the editor only on request and passes its actual generated public mint candidate, saved project ID and saved revision time. No mint key is generated, decrypted or copied by this editor. Developer and ordered final holders come from the current saved launch-wallet selection and cannot be replaced inside the editor. Extra funder/Front/Back/temporary selections use explicit account-roster root references with current wallet revisions. Duplicate role choices are disabled and independently refused by the model and server.

Every purchase, network fee, account rent and retained native reserve ceiling uses exact integer conversion from the displayed asset units. Empty values, exponent notation, rounding, overflow, missing positive buyer budgets and invalid delay units refuse review. There are no inferred fee or reserve defaults. An optional explicit shared-ceilings action copies all three entered SOL values into current rows; each wallet remains individually editable and later-added rows start empty. The last required Front buyer and a Back layer still needed by temporary holders cannot be removed without an explanation.

Review shows every ordered role/address and its limits, aggregate quote buys, native fee/rent/reserve totals, and the native aggregate. SOL principal is included only for a native quote. Token quote principal remains separate; catalog units do not establish live stock mint scaling. Seconds and milliseconds remain separately labelled. Editing invalidates review. Saving sends only declared inputs to the authenticated server; the returned complete terms must match the displayed review except for the server-owned owner binding.

Latest saved history loads independently of current context, so an archived or revised source can still show its retained plan. Different mint candidates and unconfirmed current references are labelled explicitly. A matching current snapshot can reopen as a new editable draft, after exact source, target, developer, ordered holder, quote and total validation; another review is required before saving. Exact snapshots remain idempotent on the server. This editor currently exposes the latest record; a complete browseable snapshot index remains future work.

Thirty-second request deadlines and explicit cancellation release the UI even if a transport ignores abort. Generation and mount guards prevent late responses from publishing another project's or mint's review/history. A cancelled or timed-out save is explicitly uncertain, with instructions to reload history rather than assume nothing persisted. HTML/non-object responses and invalid saved data receive readable errors. History failure prevents another save until history is readable.

The planning record is never passed to the ordinary launch consumer. Visible copy states this at entry and after save. Funding, signing and execution flags remain false. No launch consent, signing, broadcast or recovery safeguard changed. No new migration or provider setting is required beyond the already committed but separately release-gated 0109 storage migration.
